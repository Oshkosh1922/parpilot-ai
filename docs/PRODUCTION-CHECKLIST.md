# Production Activation Checklist

## Cloud foundation

- production domain and DNS
- Vercel project and Git integration
- PostgreSQL or Supabase database
- authentication and organization tenancy
- encrypted secrets and session configuration
- transactional email
- error monitoring and audit logging

## First live restaurant

- Square application credentials and OAuth redirect URL
- signed webhook handling and idempotency
- supplier-forwarding inbox
- menu, invoices, policies, and historical sales
- shadow-mode validation with one design partner

## Venture Concierge data

- Google Maps Platform key for Places and Routes
- Census geocoder and aggregate data access
- commercial listing partnership or broker feed
- food-truck/mobile-kitchen inventory source
- local permit-source discovery and citation storage
- SBDC and lender-resource linking

## Public launch safeguards

- privacy policy and consent design
- accessibility review
- tenant isolation and row-level security
- food-safety and allergen disclaimer review
- professional-advisor boundaries
- human approval for purchasing, pricing, scheduling, and public marketing
